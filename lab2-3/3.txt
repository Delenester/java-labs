1. Что такое строка?
Строка — это упорядоченная последовательность символов. В Java строка является объектом и основным носителем текстовой информации.

Для работы со строками используются классы:

String — неизменяемые (immutable) строки;

StringBuilder — изменяемые строки (не синхронизирован);

StringBuffer — изменяемые строки (синхронизирован, потокобезопасен).

2. Как создается строка?
Двумя основными способами:

1. Через оператор new:

java
String str1 = new String("Строка создана при помощи оператора new");
2. Через литерал (в кавычках):

java
String str2 = "Эта строка создана при помощи литерала.";
Важно: создание объектов через литерал возможно только в классе String. Для других классов это не работает.

3. Как выглядит массив строк?
Массив строк объявляется так же, как массив любого типа:

java
String[] auto = {"Маша", "Петя", "Вася", "Коля"};
Или через new:

java
String[] names = new String[3];
names[0] = "Иван";
names[1] = "Пётр";
names[2] = "Анна";
4. Что такое конкатенация?
Конкатенация — это операция слияния (объединения) нескольких строк в одну.

В Java для этого используется перегруженный оператор +, например:

java
String result = "Мама " + "мыла " + "раму";
5. Как происходит слияние строк?
Слияние строк в Java выполняется двумя способами:

1. Оператор + (перегружен специально для String):

java
String result = str1 + str2 + str3;
2. Метод concat() класса String:

java
String result = str1.concat(str2).concat(str3);
Метод concat() предпочтительнее для производительности в больших приложениях.
Операторы + и += — единственные перегруженные операторы в Java, которые программист не может перегружать самостоятельно.

6. Какие классы работают с регулярными выражениями?
В Java для работы с регулярными выражениями используются два класса из пакета java.util.regex:

Pattern — компилирует регулярное выражение (создаёт шаблон).

Pattern.compile(String regex) — создать шаблон;

Pattern.matches(regex, input) — проверить соответствие;

split(CharSequence input) — разбить строку по шаблону;

matcher(CharSequence input) — получить объект Matcher.

Matcher — выполняет поиск и разбор по шаблону.

find() — найти следующее соответствие;

matches() — проверить всю строку на соответствие шаблону;

group() — вернуть найденную подстроку;

replaceAll(String replacement) — заменить все совпадения.

Пример:

java
Pattern pattern = Pattern.compile("a[ex]+a");
Matcher matcher = pattern.matcher("aeeea aea axa");
while (matcher.find()) {
    System.out.println(matcher.group());
}

1. Способы создания массивов
Объявление ссылки: int[] nums; или int nums[];

Создание через new: nums = new int[4];

Объявление + создание: int[] nums = new int[5];

С инициализацией: int[] nums = new int[] {1, 2, 3};

Сокращённо: int[] nums = {1, 2, 3};

Многомерные: int[][] m = new int[3][3]; или int[][] m = {{1,2},{3,4}};

Массив в Java — объект, создаётся через new, элементы по умолчанию: 0, false, null.

2. Способы заполнения массива
По умолчанию при создании: new int[5] → все нули.

Списком значений: int[] a = {1, 2, 3};

Поэлементно: a[0] = 10;

В цикле for: for (int i=0; i<a.length; i++) a[i] = i;

Arrays.fill(a, 7); — всё одним значением.

System.arraycopy(src, 0, dst, 0, len); — копирование.

С клавиатуры через Scanner.

Случайными числами через Random.

for-each — только для чтения, менять элементы через него нельзя.

3. Типы литералов Java
Тип	Пример	Тип данных
Целый	100, 0xFF, 0b1010	int
Длинный	100L	long
Дробный	3.14, 1.5e3	double
Float	3.14F	float
Логический	true, false	boolean
Символьный	'A', '\n', '\u0041'	char
Строковый	"Привет"	String
Null	null	ссылочный
Суффиксы: L — long, F — float, D — double (необязателен).
